# Phase 8 Real-Corpus Manual Check

Use approved non-confidential copies. Never commit source files or model output.

1. Save a product-price file; verify fields and source locator.
2. Save a proposal with resolved and unresolved items; verify atomic commit and raw labels.
3. Save a payment note; verify date, Decimal amount, currency, and customer.
4. Save a 50+ row sheet; verify bounded calls and one compact review.
5. Save a budget/offer total; verify it is not classified as payment.
6. Save conflicting same-date prices; verify no silent supersession.
7. Save an ambiguous customer spelling; verify it stays unapplied.
8. Save a scanned PDF/image; verify deferred status and no invented fact.
9. Repeat approve; verify authoritative row counts do not change.
10. Reject a run; verify raw files, parsed artifacts, Qdrant chunks, and audit remain.

Record locally: precision, recall, field and entity accuracy, hallucinated count,
source-reference accuracy, conflicts, summary correctness, per-batch tokens, and
final database state. Do not commit confidential results.
